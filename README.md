# 💬 Random Quote Generator

A simple and responsive Random Quote Generator built using HTML5, CSS3, and JavaScript.

## 🚀 Features

- Displays a random quote
- Displays the quote author
- Contains 10+ quotes
- Prevents the same quote from appearing twice consecutively
- Random quote generation using Math.random()
- Share quote button
- Copy quote to clipboard when sharing is unavailable
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 Concepts Practiced

- JavaScript Arrays
- Objects
- Math.random()
- Math.floor()
- DOM Manipulation
- Event Handling
- Async/Await
- Web Share API
- Clipboard API
